# VQ C2′ 512 步 Runbook（6-bit 只给 V/O/MLP，3.1484 bit，s0）

> 背景：C 与 C3 的 rank 完全相同，差别只在索引位宽。逐矩阵拆解显示，多出来的
> 6th bit 的保真度价值约 **62% 在 MLP、36% 在 V/O、只有 2.5% 在 Q/K**——因为 Q/K 在 rank 2
> 时误差以截断为主，量化比特几乎无效。
>
> C2 失败是因为它把 6-bit 给了**包括 Q/K 在内的全部 attention**。C2′ 把 6-bit 只给
> **V / O / MLP**，Q/K 保持 5-bit，约 **3.1484 bit**。如果在 512 步不低于 C3，
> 说明“按截断主导/量化主导分配比特”是可行的；如果又掉出曲线，混合分配这条线彻底关闭。

| 步数 / seed | 512；seed 0 |

**位宽分配**

| 矩阵 | rank | 码本 |
|---|---:|---|
| Q / K | 2 / 2 | 32 词（5-bit） |
| V | 8 | 64 词（6-bit） |
| O | 8 | 64 词（6-bit） |
| MLP（w1/w2/down） | 2 | 64 词（6-bit） |

**bits/value = 3.1484**（真实 30M 模型验证）。

## 5. Cell 2 — 数据挂载 + preflight

```python
import os, subprocess, sys
from pathlib import Path

CHECKOUT = Path("/kaggle/working/benchmark-experiments")
GIT_REF = "3447ce6"
REPOSITORY = "https://github.com/SiennaDai/benchmark-experiments.git"

if not (CHECKOUT / ".git").is_dir():
    subprocess.run(["git", "clone", REPOSITORY, str(CHECKOUT)], check=True)
subprocess.run(["git", "-C", str(CHECKOUT), "fetch", "origin", "main"], check=True)
subprocess.run(["git", "-C", str(CHECKOUT), "checkout", "--detach", GIT_REF], check=True)
for item in (CHECKOUT / "src" / "data" / "frozen_tokens.py",
             CHECKOUT / "reports" / "muon_vector_int3_robustness" / "calibration_codebooks.pt"):
    assert item.exists(), f"缺少 {item}"
print("repo ok")

DATA_ROOT = Path("/kaggle/working/muon_data")
DATASET = Path("/kaggle/input/datasets/siennadai/lowp-benchmark-slimpajama-4x-v1")
assert DATASET.is_dir(), f"数据集未挂载: {DATASET}"
for name in ("manifest.json", "train.bin", "validation.bin"):
    assert (DATASET / name).is_file(), f"缺少 {name}"

link = DATA_ROOT / "data" / "slimpajama_4x"
link.parent.mkdir(parents=True, exist_ok=True)
if link.is_symlink() or link.exists():
    link.unlink()
link.symlink_to(DATASET, target_is_directory=True)

sys.path.insert(0, str(CHECKOUT / "src"))
from data.frozen_tokens import load_manifest

manifest = load_manifest(link / "manifest.json")
print("protocol_id:", manifest.get("protocol_id"))
print("fingerprint:", manifest.get("fingerprint"))

proc = subprocess.run(
    ["python", "src/main.py",
     "--recipe", "recipes/recursive_muon_plan_c2p_512_s0.json",
     "--data-root", str(DATA_ROOT), "--to-device", "cuda:0", "--dry-run"],
    cwd=str(CHECKOUT), text=True, capture_output=True)
print(proc.stdout)
print(proc.stderr)
if proc.returncode != 0:
    raise SystemExit("preflight 失败")
```

## 8. Cell 5 — 对比

```python
import json
from pathlib import Path

OUT = Path("/kaggle/working/runs")
REF = {"plan_base_512_s0": (5.680888, 3.488595),
       "plan_c3_512_s0": (5.692180, 2.731331),
       "plan_c3b6_512_s0": (5.684000, 3.231500),
       "plan_c2_512_s0": (5.695800, 2.898400)}

for run_id in ("plan_base_512_s0", "plan_c3_512_s0", "plan_c2_512_s0",
               "plan_c2p_512_s0", "plan_c3b6_512_s0"):
    path = OUT / run_id / "summary.json"
    if path.exists():
        s = json.loads(path.read_text())
        nll = s["final_validation_nll"]
        bits = s["optimizer_state"]["muon_effective_bits_per_value"]
        tag = ""
    else:
        nll, bits = REF[run_id]
        tag = "  (reference)"
    print(f"{run_id:20s} nll {nll:.4f}  bits {bits:.4f}{tag}")
```

## 9. 判读

| 结果 | 结论 |
|---|---|
| C2′ ≤ 5.687 | “按截断/量化主导分配比特”成立；3.15 bit 追平 C，值得进 4096 |
| 5.687–5.6922 | 落在 C3 与 C 之间，约在曲线上；比 C 省 0.08 bit 但没变好，不是优先候选 |
| C2′ > 5.6922（比 C3 还差） | 混合分配再次掉出曲线；这条线彻底关闭 |
