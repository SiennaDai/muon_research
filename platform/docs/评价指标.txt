### 5.2 低精度 Muon 算法的评价标准与指标体系

这一部分面向低精度 Muon 算法本身，建立单步量化阶段的评价标准。当前阶段只做单步量化；累积训练阶段的指标在 5.2.6 中单独列出，不与单步结果混用。

记 `D = G + μ·M_t` 为 NS 的实际输入（Nesterov 方向），`Φ_K` 为优化器实际使用的 K 步 Newton–Schulz 映射，`U = Φ_K(D)`。`D_hat` 为低精度重构/量化后的 D，`U_hat = Φ_K(D_hat)`；`ΔW = −lr·U + 权重衰减项`，`ΔW_hat = −lr·U_hat + 权重衰减项`。

`Φ_K` 的实现必须与优化器一致：fused QKV 整体做 NS，O 单独做；转置、Frobenius 归一化、迭代步数和系数都与训练时相同。

#### 5.2.1 指标层级

单步评价不是给低精度方法打一个总分，而是回答四个设计问题：哪个状态最敏感、哪种粒度够用、哪种误差最危险、QK 与 VO 能否使用不同精度。因此指标分为三层：

1. **主指标（评价效果）**：方向保真度、单步 loss。
2. **辅助指标（guardrail）**：Head 结构保真度。
3. **诊断指标（解释原因）**：状态保真度、更新幅度、曲率、误差分解、谱子空间等。

主指标不合成单一分数，采用二维决策 + guardrail：在 `(方向保真度, ΔL_probe)` 平面上判断可接受区域；结构保真度超过阈值时标红，但不直接否决。

#### 5.2.2 主指标一：方向保真度

全局方向保真度：

```
F_global = <U, U_hat>_F / (‖U‖_F · ‖U_hat‖_F)
```

但 Muon 的优势之一是保护小奇异方向，全局 cosine 容易被大方向主导。因此方向保真度必须按参考 `D` 的谱结构分带报告：

- 按 `D` 的奇异值分为 Top / Middle / Tail 三个带；
- 每个带 `b` 计算：
  - 左右奇异子空间保真度（Principal Angles）；
  - 更新分量保真度 `F_b = <U_b, U_hat,b>_F / (‖U_b‖_F · ‖U_hat,b‖_F)`，其中 `U_b` 是 `U` 在带 `b` 左右奇异子空间上的投影分量；
- 全局 `F_global` 只作为 summary，不作为唯一方向指标。

Tail 带的保真度是重点：Muon 对小方向的保护主要体现在这里。量化如果只破坏 Tail，全局 cosine 可能仍然很高，但 Muon 的相对优势已经被削弱。

#### 5.2.3 主指标二：单步 loss

单步阶段只能观测一步的 loss 效果，定义为：

```
ΔL_probe = L_probe(W + ΔW_hat) − L_probe(W + ΔW)
```

同时报告：

- `ΔL_fp32 = L_probe(W + ΔW) − L_probe(W)`；
- 相对退化 `|ΔL_probe| / |ΔL_fp32|`；
- 符号检查：`L_probe(W + ΔW_hat)` 应低于 `L_probe(W)`。

“正常下降、不发散、不显著变慢”是累积阶段的标准（5.2.6）。单步阶段用上述 `ΔL_probe` 作为代理，不把长期 loss 曲线混入单步评分。

#### 5.2.4 辅助指标：结构保真度（guardrail）

全精度训练中 Head 能量集中会长期保持。单步量化即使不研究累积误差传递，也不应第一步就打破这个不变量。结构保真度作为 guardrail，只保留三个指标：

- `share_L1 = Σ_h |p_h(U_hat) − p_h(U)|`；
- `top1_same`：主导 Head 是否不变；
- `γ_h` 漂移，或 `effective_heads` 漂移。

它不参与主评分，只用于报警：方向保真度和 `ΔL` 都正常但 `share_L1` 很大时，标记为“短期不伤 loss、但结构被打散”，留待累积阶段验证。

#### 5.2.5 诊断指标（解释用）

这些指标不用于评价低精度方法的效果，而用于解释主指标为什么变化：

- **状态保真度**：`D`、`M_t`、`U`、`W` 的 Frobenius 相对误差、cosine；
- **更新幅度**：`R_norm = ‖U_hat‖_F / ‖U‖_F`，以及相对范数误差；
- **误差分解**：全局 scale 误差、Head/block 相对 scale 误差、固定 norm 下的方向误差；
- **曲率**：沿 `ΔW` 的方向曲率 `κ`，用于解释 QK 与 VO 的 `ΔL` 差异；
- **谱子空间**：Principal Angles、分带相对误差；
- **存储/计算**：实际状态存储量（含 scale、码本等辅助信息）、单步重构/量化时间。

分块与整体的指标都要计算；具体块大小和边界由实验设计决定，不在评价体系里重复展开。

#### 5.2.6 使用方式与范围

**单步量化阶段**：

- 固定检查点，固定 `G`，替换一个状态为低精度版本，传播到 `U`/`ΔW`，评价主指标、guardrail 和诊断指标；
- 比较时使用**匹配相对误差**（相同相对 Frobenius 误差，而不是相同 bit-width）和 **iso-memory**（相同有效位宽/存储预算）；
- 按 Q/K/V/O、seed、node、layer 分开报告，不只报总体；
- 明确这是 `L_probe` 上的受控单步扰动，不是完整训练结果。

**累积训练阶段（下阶段）**：

- loss 曲线、最终验证 loss、发散/NaN/Loss Spike、seed 波动；
- 长期 Head 身份变化、path selection；
- 完整训练单步时间、端到端存储成本。

两类实验分开报告，不把单步替换结果与完整训练结果混为一谈。

#### 5.2.7 暂缓指标

以下指标在单步阶段不纳入评价，留待累积阶段：

- 长期 loss 曲线、最终验证损失；
- 发散、NaN、Loss Spike、随机种子波动；
- 长期 Head 身份变化、主导 Head 切换、path selection；
- 完整训练单步时间。

Hessian 曲率、Mode Connectivity、状态停滞比例等属于特定研究问题的诊断工具；在当前单步低精度实验里，曲率只作为解释 `ΔL` 差异的诊断量，不进入通用评分。
