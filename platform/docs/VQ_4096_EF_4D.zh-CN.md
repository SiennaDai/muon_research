# 长期重检 Runbook：1-bit EF 与 4D VQ（4096 步，s0，双卡）

> 目的：把两个“单步/512 步被否、但机理上可能与长期积累有关”的方法放到 4096 步上判决。
>
> - **B（1-bit 压缩误差反馈）**：3.2498 bit，对比同比特的 **C（3.2315 → 4.7756）**；
> - **4D VQ**：2.7435 bit，对比同比特的 **C3（2.7313 → 4.8061）**。
>
> 预期（写在前面，便于事后对照）：动量记忆约 20 步、`1/(1−μ)≈20`，误差累积在 ~100 步内饱和，
> 512 步已经在稳态里，因此**大概率不会翻盘**；这次是为了把“长期是否有利”这个假设正式关掉。

| `recursive_muon_plan_c3d4_4096_s0` | 4D-1024 状态（无 EF） | 2.7435 | `4796255b9fa8d40eb6f384d49f72d53e52457d9118dbc3d15e89e36c5eeb26aa` |

## 2. 判读规则

| 对比 | 翻盘判据 | 否则 |
|---|---|---|
| B（3.2498）vs C（4.7756） | B ≤ 4.7656（好 ≥0.01） | ±0.005 内 = 无差异；更差 = 否定 |
| 4D（2.7435）vs C3（4.8061） | 4D ≤ 4.7961（好 ≥0.01） | ±0.005 内 = 无差异；更差 = 否定 |

若任一翻盘，需要补 s1 复核后才能当作结论。

## 7. Cell 4 — 两个 4096 run（B → GPU0，4D → GPU1）

```python
import json, os, subprocess, threading, time
from pathlib import Path
import torch

CHECKOUT = "/kaggle/working/benchmark-experiments"
OUT = Path("/kaggle/working/runs")
NGPU = max(1, torch.cuda.device_count())
print("visible GPUs:", NGPU)

PLAN = [
    (0, "recipes/recursive_muon_plan_c3ef1_4096_s0.json", "plan_c3ef1_4096_s0"),
    (1, "recipes/recursive_muon_plan_c3d4_4096_s0.json", "plan_c3d4_4096_s0"),
]
RUN_IDS = [run_id for _, _, run_id in PLAN]

by_gpu = {}
for gpu, recipe, run_id in PLAN:
    by_gpu.setdefault(gpu % NGPU, []).append((recipe, run_id))
print("assignment:", {g: [r for _, r in items] for g, items in by_gpu.items()})

def worker(gpu, items):
    env = os.environ.copy()
    env.update({
        "DATA_ROOT": "/kaggle/working/muon_data",
        "OUTPUT_ROOT": str(OUT),
        "MAX_WALL_SECONDS": "39600",
        "KAGGLE_INSTALL_DEPS": "0",
        "KAGGLE_GPU_INDEX": str(gpu),
    })
    for recipe, run_id in items:
        if (OUT / run_id / "summary.json").exists():
            print(f"[gpu{gpu}] {run_id} already complete, skipping", flush=True)
            continue
        print(f"[gpu{gpu}] launch {run_id}", flush=True)
        subprocess.run(["bash", "scripts/run_kaggle.sh", recipe, run_id],
                       cwd=CHECKOUT, env=env, check=True)

def last_eval(run_id):
    path = OUT / run_id / "metrics.jsonl"
    if not path.exists():
        return None
    last = None
    with path.open() as fh:
        for line in fh:
            event = json.loads(line)
            if event.get("event_type") == "eval":
                last = event
    return last

threads = [threading.Thread(target=worker, args=(g, items), daemon=True)
           for g, items in by_gpu.items()]
for thread in threads:
    thread.start()
while any(thread.is_alive() for thread in threads):
    parts = []
    for run_id in RUN_IDS:
        event = last_eval(run_id)
        parts.append(f"{run_id}: {event['completed_updates']}/{event['nll']:.4f}"
                     if event else f"{run_id}: -")
    print(" | ".join(parts), flush=True)
    time.sleep(60)
print("runs finished", flush=True)
```

## 8. Cell 5 — 对比

```python
import json
from pathlib import Path

OUT = Path("/kaggle/working/runs")
REF = {"plan_c3b6_4096_s0": (4.7756, 3.2315),   # C
       "plan_c3_4096_s0": (4.8061, 2.7313)}    # C3

rows = []
for run_id in ("plan_c3b6_4096_s0", "plan_c3_4096_s0", "plan_c3ef1_4096_s0", "plan_c3d4_4096_s0"):
    path = OUT / run_id / "summary.json"
    if path.exists():
        s = json.loads(path.read_text())
        nll = s["final_validation_nll"]
        bits = s["optimizer_state"]["muon_effective_bits_per_value"]
        tag = ""
    else:
        nll, bits = REF[run_id]
        tag = "  (reference)"
    rows.append((run_id, nll, bits))
    print(f"{run_id:24s} nll {nll:.4f}  bits {bits:.4f}{tag}")

print("\nB(EF) vs C:", f"{rows[2][1]-rows[0][1]:+.4f}")
print("4D vs C3:  ", f"{rows[3][1]-rows[1][1]:+.4f}")
```
